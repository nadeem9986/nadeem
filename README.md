## Local preview

```bash
git clone https://github.com/nadeem9986/nadeem.git
cd nadeem
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploying to GitHub Pages

1. Keep `index.html` at the repository root.
2. GitHub: **Settings > Pages**, select the `main` branch, save.
3. For a custom domain, point the `CNAME` DNS record at `nadeem9986.github.io`.
