## Local Development Setup

To run and preview the portfolio application locally on your machine:

```bash
# Clone the repository
git clone https://github.com/nadeem9986/nadeem.git
cd nadeem

# Serve locally using Python HTTP server
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in any modern web browser.

## Deployment & Hosting Guide

### **Deploying to GitHub Pages**
1. Ensure `index.html` is at the root directory of the repository.
2. In GitHub, navigate to **Settings > Pages**.
3. Select the `main` branch as the build source and save.
4. If using a custom domain, configure the `CNAME` record in DNS settings to point to `nadeem9986.github.io`.
